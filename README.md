# Corpers Connect

Clickable front-end prototype of Corpers Connect: a social network and an opportunity marketplace (jobs, items, accommodation, events) for NYSC corps members. Both halves are equal pillars.

- Single static file: `index.html` (no build step)
- Sample data only; nothing is saved or sent
- Deploy: import this repo in Vercel and click Deploy
- Sample media lives in `media/` (photos from picsum.photos, portraits from randomuser.me, short CC0/test videos). Swap in real NYSC photos and videos before any public demo.
